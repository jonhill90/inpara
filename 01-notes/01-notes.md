# Notes

**Purpose**: everything we wrote ourselves and know what it is (wizard step 6 in [ORGANIZE.md](../99-meta/ORGANIZE.md)). A note about something someone else made still lives here, and links to the captured original in `04-resources/`.

## Lettered folders

Each folder is created when its first note arrives, and then gets one line in the list below. Lettered folders are flat: the notes sit directly in them, named by id.

| Folder | Holds | Template |
|---|---|---|
| `01a-atomic/` | one idea per note, under the headings Notes, Thoughts, Links | [atomic-note.md](../99-meta/templates/atomic-note.md) |
| `01d-daily/` | a log of one day's work, named `YYYYMMDD.md` | [daily-log.md](../99-meta/templates/daily-log.md) |
| `01h-handbook/` | reference pages kept current that hold many ideas, each with a `handbook-kind`: a vocabulary, a policy, a profile, a catalogue | [handbook-page.md](../99-meta/templates/handbook-page.md) |
| `01h-handbook/01hr-runbooks/` | steps a person or an agent follows to do one thing | [handbook-page.md](../99-meta/templates/handbook-page.md) |
| `01i-incidents/` | one problem: what broke, the root cause, the fix | none yet |
| `01m-meetings/` | one meeting: attendees, agenda, notes, next steps, named `meeting-<id>.md` | none yet |
| `01r-research/` | registered research batches: hubs in `01rb-batches/`, notes by kind in `01ra` to `01rs` | none yet |
| `01s-samples/` | code or prototypes built as examples | none yet |
| `01t-tasks/` | one note per task, `TASK-NNNN`, its state in front matter; the plan is `plan-order` on tasks; the hub `01t-tasks.md` lists every task by state | [task.md](../99-meta/templates/task.md) |
| `01w-worklogs/` | one work session on one subject: what was done, files changed | none yet |

Files we made that are not notes go in the sub-kinds of the kind folder whose notes cite them: `<letters>d-data/`, `<letters>s-scripts/`, `<letters>i-images/` and `<letters>p-pages/`, for example `01h-handbook/01hd-data/`.

**Atomic or handbook?** A note on one idea is atomic, even when it is edited later. A reference page we keep editing that holds many ideas is a handbook page; a plan or a dashboard never is. **Worklog or day log?** A worklog covers one session on one subject; the day log covers the whole day and links to it. **Research or runbook?** An option comparison is research; a how-to is a runbook.

## Principles

- **One idea per atomic note.** Shared facts get their own note that both notes link to.
- **Written in your own words.** Understandable weeks later without the context.
- **Named by its id.** `2026110519300001.md`; the title, area and tags are in front matter, and the folder and `type` say what kind it is.
- **Linked from a map.** Every note is linked from at least one area or project map, with a reason.
- **Join, never copy.** If a note on the subject exists, add to it.
