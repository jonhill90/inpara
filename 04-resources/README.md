# Resources

**Purpose**: things someone else made that we keep to reference (wizard step 3 in [ORGANIZE.md](../99-meta/ORGANIZE.md)). We did not write them.

## Lettered folders

Each folder is created when its first capture arrives, and then gets one line in the list below.

| Folder | Holds |
|---|---|
| `04p-pages/` | captured web pages and snipped pages |
| `04d-documents/` | papers, PDFs, exports |
| `04r-repos/` | repository captures: outside repositories, their files and code |

## Rules

- **Our notes about a resource are not a resource.** They go in `01-notes/` and link to it. A captured page holds only the capture and a short front matter block (see [resource-capture.md](../99-meta/templates/resource-capture.md)).
- **Name by what it is,** never by where it came from in some other folder.
- **Captured files keep their original names** inside the item, and the name, link and copy checks skip them.
- **Every resource is linked from a map,** with the reason it matters there.
- **Be selective.** Capture what you will consult again, not every interesting link.
