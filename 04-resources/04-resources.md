# Resources

**Purpose**: things someone else made that we keep to reference (wizard step 3 in [ORGANIZE.md](../99-meta/ORGANIZE.md)). We did not write them.

## Lettered folders

Each folder is created when its first resource arrives, and then gets one line in the list below. Lettered folders are flat: one Markdown clipping per doc, and one resource note `<resource>.md` per resource that links its clippings.

| Folder | Holds |
|---|---|
| `04c-clippings/` | clippings of web pages and documents made by someone else |
| `04d-documents/` | papers and documents: the note in git, the file kept locally |
| `04h-harness/` | agent harness material: `04hp-prompts/` for exported chat threads, one resource note and a local backup |
| `04l-learning/` | courses and curricula |
| `04r-repos/` | clippings of repository READMEs and docs, and links to the repos |
| `04v-video/` | videos and their transcripts |

## Rules

- **Our notes about a resource are not a resource.** They go in `01-notes/` and link to it. A clipping holds only the captured text and its front matter (see [resource-capture.md](../99-meta/templates/resource-capture.md)).
- **Only the Markdown note is in git.** A PDF, video, repository copy, raw page or scraped dump is kept locally under `.cache/`, which git ignores; the note records the source, the date, and each file's size and sha256.
- **Link instead of copying.** Link to a repository or page rather than keeping a copy of it.
- **Every resource is linked from a map,** with the reason it matters there.
- **Be selective.** Capture what you will consult again, not every interesting link.
