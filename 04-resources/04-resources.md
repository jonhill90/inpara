# Resources

**Purpose**: things someone else made that we keep to reference (wizard step 3 in [ORGANIZE.md](../99-meta/ORGANIZE.md)). We did not write them.

## Lettered folders

Each folder is created when its first resource arrives, and then gets one line in the list below. Lettered folders are flat: one link note per thing, never a copy of it.

| Folder | Holds |
|---|---|
| `04c-clippings/` | web pages made by someone else: one link note each, no copied text |
| `04d-documents/` | papers and documents: one link note each, the file not kept |
| `04h-harness/` | agent harness material: `04hp-prompts/` for exported chat threads, one resource note and a local backup |
| `04l-learning/` | courses and curricula |
| `04r-repos/` | one link note per repository our notes cite, `<owner>-<repo>.md`, made by a script |
| `04v-video/` | videos and their transcripts |

## Rules

- **Our notes about a resource are not a resource.** They go in `01-notes/` and link to it. A resource note holds only its front matter, the link and the notes that cite it (see [resource-capture.md](../99-meta/templates/resource-capture.md)).
- **Link, never copy.** The text, PDF, video, repository or raw page is not kept in git: read it at its URL, or keep a local copy under `.cache/`, which git ignores.
- **Every resource is linked from a map,** with the reason it matters there. A repo note in `04r-repos/` is covered by the notes that cite it.
- **Be selective.** Capture what you will consult again, not every interesting link.
