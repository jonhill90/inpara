# Inbox

**Purpose**: immediate capture of all thoughts, ideas, insights, and findings. This is the last answer of the wizard in [ORGANIZE.md](../99-meta/ORGANIZE.md): a file goes here only when no earlier question gets a yes yet.

## Guidelines

- **Capture immediately.** Don't worry about formatting or organization.
- **Keep it simple.** Quick notes, voice memos, screenshots, links.
- **Sort daily.** Run the wizard on each item within 24 hours when possible.
- **No pressure.** This is a safety net, not a filing system.

## What goes here

- Random thoughts and insights
- Meeting notes and observations
- Code snippets and error messages
- Interesting links and articles
- Voice notes, screenshots and images

## Sorting

Run the wizard on each item. Most items become one of these:
- an **atomic note** in `01-notes/01a-atomic/`, or a line added to a note that already exists (wizard step 0: join, never copy)
- a **task** in `01-notes/01t-tasks/`, or a line in the day log in `01-notes/01d-daily/`
- a **clipping** in `04-resources/04c-clippings/`, with our own note about it in `01-notes/`
- a **plan or status page** for a project, as a handbook note linked from the project map
- **trash**, if it no longer matters

## Lettered folders

Each is made when its first item arrives, and then gets one line in Contents below.

| Folder | Holds |
